# Практическая работа №1.1 - Первая модель (Sequelize + SQLite)

## Описание предметной области
В данной работе реализована консольная модель для учета автомобилей в автосалоне. 

## Поля таблицы `cars`
- `brand` (STRING) — марка автомобиля (обязательное).
- `model` (STRING) — модель автомобиля (обязательное).
- `year` (INTEGER) — год выпуска.
- `price` (FLOAT) — цена в рублях.
- `isAvailable` (BOOLEAN) — доступен ли для продажи (по умолчанию true).

*Примечание: Sequelize автоматически добавляет к модели поля `id` (первичный ключ), `createdAt` и `updatedAt`.*
